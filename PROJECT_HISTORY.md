# История проекта bak7580 (bak7580.ru)

Этот документ ведёт историю разработки, архитектуру и список всех внесённых изменений. Ассистенты и разработчики должны сверяться с этим файлом и дополнять его при внесении новых правок.

---

## 📌 О проекте
- **Сайт**: `bak7580.ru`
- **Назначение**: Персональный сайт артиста/музыканта bak7580 с дискографией, плеером, видео и ссылками на соцсети/платформы.
- **Стек**: Vanilla HTML5, CSS3, JavaScript (ES6+), Node.js (локальный сервер разработки), Apache (.htaccess для боевого хостинга).

---

## 📁 Структура проекта
- `index.html` — Главная страница сайта (навигация, видео, ссылки на Spotify, GameJolt, Scratch, соцсети).
- `music.html` — Страница «Вся музыка» с кастомными плеерами для всех альбомов (27+ треков).
- `server.js` — Локальный HTTP-сервер на Node.js с поддержкой Range-запросов (HTTP 206) для плавной перемотки аудио и видео.
- `.htaccess` — Конфигурация для Apache/хостинга (красивые URL без расширения `.html`: `bak7580.ru/music`).
- `Запустить_сайт.cmd` — Скрипт быстрого запуска локального сервера в один клик.
- `tracks/` — Аудиофайлы треков, сгруппированные по папкам альбомов.
  - `1_pokhod_v_magazin/` — Альбом 1 («Поход в магазин»).
  - `2_delo_v_shlyape/` — Альбом 2 («Дело в шляпе»).
  - `3_neonovyj_priliv/` — Альбом 3 («Неоновый прилив»).
  - `4_raznye_komnaty/` — Альбом 4 («4 разные комнаты»).
- `album1.jpg` – `album4.jpg` — Обложки альбомов.
- `gazan.html`, `sixseven.html` — Дополнительные страницы с видео (`gazan.mp4`, `67.mp4`).

## 📝 Хронология изменений

### [2026-10-04 — 2026-10-05]
1. **Альбом «4 разные комнаты»**:
   - Скачаны и структурированы треки 4-го альбома (`Убей меня`, `Забытый проигрыватель`, `Кабель под ковром`, `Слишком облачно`, `Треснувшее стекло`, `Шум за стеной`).
   - В аудиофайлы вшиты метаданные и обложка (`album4.jpg`).
   - В `music.html` добавлен блок 4-го альбома с треклистом, кастомными кнопками и таймингами.

2. **Интеграция ссылок на платформы**:
   - Добавлены ссылки на GameJolt, Scratch и официальный профиль Spotify (`spotify:artist:4APe1ZlChJgSuLSTiq4HEh`).

3. **Красивые URL (удаление `.html` в браузере)**:
   - В корне создан `.htaccess` с директивами `mod_rewrite`, чтобы при открытии `bak7580.ru/music` не требовалось писать `.html`.
   - Навигационные ссылки в меню скорректированы под чистые адреса.

4. **Полное исправление перемотки треков (Audio Seeking)**:
   - **Проблема**: В браузере (Chrome/Edge) при клике на таймлайн трек сбрасывался на 0:00 или зависал.
   - **Причина 1**: В `server.js` не было обработки заголовков `Range: bytes=X-Y` — сервер отдавал код `200 OK` с начала файла вместо `206 Partial Content`.
   - **Причина 2**: В `music.html` плееры имели атрибут `preload="none"`, из-за чего браузер не знал длительность треков до первого клика.
   - **Решение**:
     - В `server.js` реализован полноценный стриминг с поддержкой `HTTP 206 Partial Content`, расчётом `Content-Range` и `Content-Length`.
     - В `music.html` все 27 плееров переведены на `preload="metadata"`. Теперь таймлайн активен сразу, перемотка работает безупречно на любую секунду.

## ⚙️ Правила для разработки
1. При добавлении новых альбомов/треков обязательно проверять наличие атрибута `preload="metadata"` у тегов `<audio>`.
2. Локальный сервер запускать через `Запустить_сайт.cmd` или `node server.js`.
3. Все изменения фиксировать в этом файле `PROJECT_HISTORY.md`.
