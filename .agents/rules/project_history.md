# Память проекта bak7580

1. **Контекст проекта**:
   - При работе с этим репозиторием всегда учитывай информацию из файла `PROJECT_HISTORY.md` в корне.
   - В нём описана архитектура, список треков, настройки сервера (`server.js`) и логика плеера (`music.html`).

2. **Фиксация изменений**:
   - После выполнения любых значимых доработок (добавление треков, страниц, рефакторинг, исправление багов) обязательно дополняй раздел «Хронология изменений» в `PROJECT_HISTORY.md`.
   - Это гарантирует, что в любом новом чате контекст работы не потеряется.
